# Security Policy

## Supported Versions

Security fixes are released for the latest published version of `@drincs/pixi-vn`.

## Reporting a Vulnerability

Please do not open a public issue for security problems. Report them privately through
[GitHub's private vulnerability reporting](https://github.com/DRincs-Productions/pixi-vn/security/advisories/new)
for this repository.

Include the affected version, a description of the issue, and steps to reproduce it. You can expect an
acknowledgement within a few days; we'll keep you updated until the issue is resolved.
